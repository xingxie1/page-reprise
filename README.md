# 循页 · PageReprise

给考研自习用的 Windows 和 Android 错题本。打开就能看到今天该做哪一本。政治、英语、数学和 408 的四门课各有自己的普通本与永久重点本。

未清零的题按 **1 / 7 / 14 天**复习；正式复习中答错或猜中后，按 **1 / 3 / 14 天**重开。两次清零升入同科重点本。三连对结束排期，但不会删除题图或历史。

产品规则、设备和验收场景见[开发文档](循页-开发文档.md)。本仓库不存放个人错题、服务密钥或 Android 签名私钥。

## 把题图变成阅读稿

1. 在录题页或「设置 → 图片识别」选择「导入图片时转为文字」。首次开启时填自己的 DeepSeek API Key，按该 Key 计费。新设备默认只存图，从 0.5.0 升级且已有 Key 的设备沿用自动转写。循页记住此设备上当前账号的选择。[创建个人 Key](https://platform.deepseek.com/api_keys)
2. Android 支持相册、Notein 分享和系统截图，Windows 支持选文件、拖放和粘贴。开关开启时，新导入的题干图和答案图会分别转写。关闭后只存原图，某张图需要文字时点图下的「识别这张图」。以后打开开关只影响新导入的图。关闭会取消当前识别队列，已生成的稿仍可阅读。已经发送给 DeepSeek 的请求可能已产生费用。
3. 登录同一循页账号的设备在同步后都能阅读，查看和导出阅读稿无需 Key。手机默认显示阅读稿，平板和电脑宽屏默认左图右文。复习时点「核对答案与错因」才会展开答案。可调字号，也可切回原图放大查看。
4. 核对「〔待核对〕」或「〔图示见原图〕」时，进入「编辑题目」，在对应图片旁点「校对阅读稿」，应用后保存。识别失败可对单张图重试。题目详情里的「导出 Markdown」会把题干和答案一起写入一个 UTF-8 文件。整库 ZIP 备份另含原图和作答记录。
5. 同一次识别还会提取一个核心知识点，填进「知识点（显示在题号后）」。多图题按题干图片顺序取首个能判断的考点，题干信息不足时采用答案图的建议。你可以改名、清空或点「采用识别的知识点」。已有阅读稿的旧题可在编辑时点「补识别知识点」，保留校对过的正文。

密钥按设备、按循页账号存放，Android 使用系统密钥库，Windows 使用当前用户的 DPAPI。录题设备直接将当张图片发送给 DeepSeek。循页云端同步保存的题目、原图和阅读稿。恢复备份、在另一台设备打开题目和重复同步均不会触发识别。题干与答案各有一套转写指令。[查看内置提示词](core/src/main/resources/reading/transcription.md) · [DeepSeek 图像接口](https://api-docs.deepseek.com/zh-cn/guides/vision/)

## 今日复习和题号

Windows、手机和平板使用「石墨回环」图标和深色界面。首页用荧光黄绿标出待复习题数、录题按钮和重点本入口。普通本与重点本保留文字标签，题干和答案图片按原色显示。

点击首页「今日复习」可查看所有到期题，包括往日逾期的题，按首次添加时间从早到晚排列。点一题开始复习，完成后回到清单。也可以从某科的普通本或重点本成组复习。

点首页科目名称或卡片空白处会进入本科普通本。题本页上方并排显示「普通错题本」「重点错题本」，点按钮即可切换，实心底色标出当前题本。首页卡片里的「普通」「重点」按钮仍可直达对应的本。

在手机和平板上用手指左右滑动，在 Windows 上按住鼠标左键左右拖动。切换哪一项由按下的位置决定。

| 开始滑动的位置 | 左滑 | 右滑 |
| --- | --- | --- |
| 题目列表的搜索框上方 | 进入本科永久重点本 | 回到本科普通本 |
| 搜索框下方，包括列表空白处 | 下一项筛选，依次为「全部」「已到期」「已掌握」「待核对」 | 上一项筛选 |

拖动时，两页并排横向平移，按钮的选中底色跟随同一进度移动。松手完成切换，短拖、取消或拖回起点会回到原页。上方切换题本，下方只滑动筛选按钮下面的题目。搜索框可照常选字，筛选时宽屏右侧保留正在预览的题。也可以直接点题本或筛选按钮。

每科单独从 `#001` 编号，普通本和重点本共用该科的序列。有知识点时显示「第 014 题 · 数列极限」。知识点空白时，列表显示原有题号和已填写的题干文字。完整题干可在详情中阅读。可以用题号、知识点或题干搜索。408 固定分为数据结构、计算机组成原理、操作系统、计算机网络。原先存进「408」的题保留在原本，可在详情里更正科目。

## 在 Windows 上开始

从同一发布页下载 `PageReprise-0.5.2-Windows-x64.exe`，双击安装后从桌面或开始菜单打开「循页」。程序自带运行环境，适用于 Windows 10 / 11 x64。[下载循页](https://github.com/xingxie1/page-reprise/releases/latest)

- 按 **Win + Shift + S** 截图，切回循页按 **Ctrl + V**。也可以把图片文件拖进窗口。第一批进入题干，同一道题再粘贴或拖入会追加到答案。点「添加题干图」或「添加答案图」默认打开 Windows 当前用户的「图片」文件夹，可多选或浏览其他目录。
- 窗口较宽时，左侧选题、右侧看详情。单击题图进入全屏，滚轮缩放，放大后按住鼠标拖动，**Esc** 回到原处。
- 题库和草稿保存在当前用户的 `%LOCALAPPDATA%\PageReprise\data`。关闭录题窗口时可暂存草稿，下次从首页继续。

## 在平板和手机上开始

1. 下载 `PageReprise-0.5.2.apk`。也可以把同一个 APK 直接传到两台设备安装。第一次打开就能在本机录题和复习。[循页 0.5.2 发布页](https://github.com/xingxie1/page-reprise/releases/tag/v0.5.2)
2. 在循页点「录入一道题」，或在系统截图、相册的分享菜单中选「循页」。选科后保存；长题可有多张题图和答案图，可裁切、排序、补图。Notein 只需能分享图片，不能直分享时用系统截图即可。
3. 次日北京时间 00:00 起，首页对应科目的本会显示待办。做题时答案折叠，猜对按没做对处理。仅打开、稍后、手动抽练都不改变排期。第二次清零须确认，题目只移到同科永久重点本。
4. 多设备同步使用**自己的 Supabase 服务**。按[云端启用指南](docs/cloud.md)配置，再在 Windows、手机和平板登录同一个受邀账号。从本机试用转入账号须手动确认，好友使用不同账号。设置内可以导出或预览恢复备份，夸克网盘只用于手动存放该文件。

点「添加题干图」或「添加答案图」默认从系统相册选图。支持指定起始页的系统会直接打开「相册」，可以进「截屏」选多张图。较旧系统会使用可用的图库或文件选择器。录题页接收第一批分享图时会填入题干。保持同一道题在编辑中，再分享的截图会追加到答案。多页题干可以用图下的「移到题干」调整。点预览图可全屏阅读，双击切换倍率，点右上角关闭。

普通本的题目详情提供「删除错题」。删除后进入本科回收站，满 168 小时到期。期限内恢复会带回原图、复习记录和原到期日。永久重点本继续永久保留。在云端使用本版，请将自己的设备都更新到同一版本，并完成[回收站云端配置](docs/cloud.md#启用回收站的云端清理)。

## 从另一台设备查看刚存的题

同一账号正式保存一道题后，循页先写入本机，再自动向自己的云服务器上传。等录题设备显示「已同步」，在另一台设备打开循页、切回前台，或点「设置 → 立即同步 / 重试」即可拉取。题目文字可能先于图片显示。一直停在原页面的设备没有实时推送，离线保存的题会在下次联网同步时上传。

手动导出的 ZIP 是导出当时的题库副本。继续录题后，需要再次导出才能得到新的备份文件。草稿只在录入它的设备上保存。

## 自动更新

使用 0.3.1 或更早版本的设备需要先手动覆盖安装一次当前版。0.4.0 及后续版本打开循页就会联网检查公开发布页，有新版时自动下载并校验。录题或复习途中会等到回到首页再安装。在「设置 → 版本更新」可查看状态或重试。

Windows 安装版会关闭旧窗口，安装后自动重开。手机和平板第一次更新时，根据提示允许循页安装应用。HyperOS 如显示系统安装确认，点「安装」即可。应用安装包与个人题库分别存储，云同步仍使用自己的 Supabase 账号。

## 构建与发布

需要 JDK 17、Android SDK Platform 35、Build Tools 34.0.0 / 35.0.0。设置 `JAVA_HOME` 和 `ANDROID_HOME`，或使用 Android Studio 的本地 SDK 位置。Gradle Wrapper 固定版本并校验发行包的 SHA-256。

| 任务 | Windows PowerShell 7 |
| --- | --- |
| Android 单元测试与构建 | `.\gradlew.bat :core:test :app:assembleDebug :app:assembleRelease` |
| Windows 测试 | `.\gradlew.bat :desktop:test` |
| Windows 自包含程序 | `.\scripts\package-windows.ps1 -Format Portable` |
| Windows 每用户安装包 | `.\scripts\package-windows.ps1 -WixBin C:\tools\wix3`（WiX 3.14） |
| Android 测试设备验收 | `.\gradlew.bat :app:connectedDebugAndroidTest` |
| 用固定私钥签出可持续覆盖安装的 APK | `.\scripts\sign-local.ps1 -UnsignedApk app/build/outputs/apk/release/app-release-unsigned.apk` |

macOS / Linux 使用 `./gradlew`。Windows 签名工具把成品放在 `dist/PageReprise-0.5.2.apk`，用 `apksigner` 验签并报告摘要。首次签名在当前 Windows 用户的 `%LOCALAPPDATA%/PageReprise/signing` 创建专用密钥，口令用 DPAPI 保护。请离线备份签名密钥，并将口令另存在自己的密码管理器；仅复制 DPAPI 文件不能在另一台电脑解密。不要把签名材料放进 Git。后续升级使用同一私钥和递增的版本号。

两个安装包生成后，在同一工作目录用 PowerShell 7 运行 `.\scripts\sign-update.ps1`。它用原有私钥签出包含版本、文件大小和 SHA-256 的 `dist/PageReprise-update.json`。先建立草稿 Release，再把这份清单、同版 APK 和 Windows x64 安装包一起上传。核对附件后将与 `gradle.properties` 对应的 `v版本号` 发布为最新正式版。应用通过稳定地址读取已签名的清单。[公开发布页](https://github.com/xingxie1/page-reprise/releases/latest)

## 双端验收

Windows 和 Android 直接编译同一份界面、同步和复习逻辑，以同一版本号发布。后续变更的验收约定见 [AGENTS.md](AGENTS.md)。

- [Windows 构建](../../actions/workflows/windows.yml)执行共享规则、桌面存储和界面测试，并实际打开打包后的程序。

- [Android 构建](../../actions/workflows/android.yml)：推送时运行排期、离线冲突和备份单元测试，并生成 debug APK、测试 APK 和**未签名** release APK。流水线的 debug 身份用于测试，不作为长期分发签名。
- [权限检查](../../actions/workflows/access.yml)：在一次性 PostgreSQL 中检查邀请码、只追加操作、不同账号及私有题图的隔离。
- [云接口联测](../../actions/workflows/cloud-smoke.yml)：按需在临时 Supabase 测试两个登录会话、实际上传下载、重复提交和好友隔离，不使用真实用户资料。[Android 设备验收](../../actions/workflows/device.yml)在一次性模拟器执行实际页面操作。
- [Android 正式版升级验收](../../actions/workflows/upgrade.yml)可在最新版本发布后运行。指定上一个带自动更新的签名版本，在手机和平板模拟器打开旧版，由应用下载公开安装包，再从系统包管理器读取升级结果。
- 目标真机为小米 Pad 7 和小米 14 Pro，仍须验证 HyperOS 私下安装、Notein 分享菜单和手写题图清晰度。应用不申请通知或全盘读取权限。知识点复习和自动判分留待后续版本。
